HTML/CSS Junho 2025

Etapa 6: construindo meu portfólio com HTML

Chegamos à etapa final do Projeto Integrador. Nessa etapa, integrei tudo que aprendi sobre HTML semântico, CSS com variáveis e JavaScript para criar um site pessoal completo...

A etapa 6 do Projeto Integrador foi a mais desafiadora e também a mais recompensadora. Precisei criar quatro páginas HTML integradas: início, currículo, blog e contato. Aprendi como organizar o código com um arquivo CSS e JS compartilhado, o que economiza muito trabalho e mantém o visual consistente.

O maior desafio foi fazer a responsividade funcionar em celulares. Aprendi sobre media queries e como o CSS muda o comportamento dos elementos em telas pequenas.

JavaScript Maio 2025

Minha primeira função em JavaScript

Quando escrevi minha primeira função que realmente funcionou, foi um momento de muito orgulho. Entender o que é um parâmetro, retorno e escopo foi um passo importante...

Lógica de Programação I me ensinou que programar não é só escrever código — é pensar de forma estruturada antes mesmo de abrir o editor. A função é a menor unidade de organização do código, e entendê-la mudou a forma como vejo problemas.

Dica que aprendi: antes de programar, escreva em português o que a função precisa fazer. Parece simples, mas evita muita confusão.

Lógica Abril 2025

Algoritmos: pensar antes de digitar

A disciplina de Lógica de Programação me ensinou que o maior erro de quem está começando é abrir o editor antes de entender o problema. Fluxogramas e pseudocódigo salvam horas de retrabalho...

Fluxograma não é coisa antiga ou inútil. É a ferramenta mais honesta que existe para visualizar a lógica antes de traduzir para qualquer linguagem. Erros de lógica são muito mais baratos de corrigir no papel do que no código.

Na aula de Introdução à Informática, descobri como computadores funcionam por baixo dos panos — e isso mudou completamente como eu enxergo o que escrevo.

HTML/CSS Março 2025

HTML semântico: a diferença que faz diferença

Por que usar <article> em vez de <div>? A resposta está na acessibilidade e no SEO. Aprendi que o HTML não é só estrutura — é comunicação com o navegador...

Tags como header, main, footer, nav, section e article dizem ao navegador o que cada parte da página significa. Um leitor de tela para pessoas cegas usa essas informações para navegar corretamente.

Quando aprendi isso, percebi que escrever HTML com divs para tudo é como escrever um livro sem capítulos, parágrafos ou títulos. O conteúdo até está lá, mas ninguém consegue se orientar.
